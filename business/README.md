## Weekly Rhythm (Once Systemized — Month 3+)

**Monday morning, 2 hours total:**
1. Open weekly dashboard → review exception calls (30 min)
2. Reply to any client messages (20 min)
3. Review each client's call volume + booking rate (20 min)
4. Send weekly performance emails (AI-drafted, you approve) (15 min)
5. Outreach check — review reply queue, approve next batch (35 min)
